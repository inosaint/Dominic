**Dominic is in alpha, please reach out to Kenneth on https://x.com/kenneth for feedback or create an issue at https://github.com/inosaint/Dominic/issues**

Dominic is built on the idealogy of [Dignified Technology](https://dearhermes.com/read/kfniw9y/what-does-a-tool-owe-you), where AI doesnt design for us, but helps us design better by providing feedback.

### How does it work?

- Add your Anthropic or OpenAI key and select the model you want to use.
- Select any frame in your Figma and ask Dominic to review.
- Dominic's specialist agents critique your work across accessibility, visual hierarchy, spacing, copy, and more
- Dominic will drop actionable feedback as notes or annotations directly on your canvas.
- Tapping on each note in the chat zooms to the particular feedback node/layer as well.

### Features

- One-click review from multiple expert agents (accessibility, layout, copy, UX, etc.)
- Supports Anthropic (Claude) and OpenAI (GPT-4o) — bring your own API key
- Output as sticky notes, Figma annotations, or both
- Optional screenshot mode for richer visual context (costs more tokens)
- (experimental) Create custom review agents with your own system prompts
- (experimental) Chat back and forth with agents for follow-up questions


*Note: Your API key is stored locally and never leaves your machine. Dominic sends only the selected frame data and optional screenshot to the LLM provider you choose.*
